## Skills Hub

本仓库将分散在独立 GitHub 仓库中的 Skills 同步为 `skills/` 下的真实文件，便于只识别统一 Skills 目录的工具安装和读取。

克隆本仓库后，可以选择：

- 将 `skills/` 下所需目录复制到目标工具的 Skills 目录
- 在工具支持时直接使用本仓库的 `skills/` 目录

## 收录与审查

- 使用 [Skill 收录申请](../../issues/new?template=skill-request.yml) 提交上游仓库和 Skill 路径，其余收录信息由工作流从上游内容中提取
- 收录 PR 只新增对应的 `sources/<name>.json` 和 `skills/<name>/**`，确定性校验与变更审查通过后才会自动合并

## 同步与维护

- GitHub Actions 从东八区时间 `00:00` 开始，每隔 6 小时运行一次，也支持手动触发
- 仅在对应 Skill 内容变化并同步成功时更新其独立来源配置，没有变化时文件保持不变
- 修改 `sources/` 的 PR 合并后会单独重建 README，避免多个 Skill PR 修改同一个清单文件
