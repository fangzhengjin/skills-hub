# CINEMA DNA 3.1.1｜画风保真、连续分镜与视频运镜

## 0. 目标与适用范围

让电影感来自摄影机的位置、人物与空间的关系、可见动作、实际光源和镜头之间的剪辑，而非形容词、滤镜或堆砌颗粒。

只有用户未指定媒介、也没有要求保留参考画风时，才默认真人实景电影质感。指定手绘、动画、产品或商业空间时，服从相应媒介与资产要求，不把“非真人”“广告项目”本身判为失败。片名、海报、视觉体系只在用户要求时追加。

处理顺序：用户给定的剧情与资产事实 → 连续性和空间可行性 → 镜头与动作 → 审美。下列协议优先于旧风格参考中的固定节拍、构图配额、参考图隔离和媒介限制。

## 1. 先确定交付，不自动扩大任务

| 意图 | 交付 |
|---|---|
| 单张电影静帧 | 1 张独立镜头 |
| 三联、默认电影测试 | 3 张独立镜头，再纵向拼接 |
| 九镜、九张讲故事 | 9 张独立镜头，再外部拼成 3×3 |
| 分镜视频提示词、运镜方案 | 对应镜数的导演卡与可复制短提示词；不自动生成图或视频 |
| 分镜图并附视频提示词 | 独立图像与对应导演卡；明确图像是首帧、中点还是尾帧 |
| 实际生成视频 | 先核验可用视频工具及能力，只执行用户授权范围 |

数量以用户要求为准。未指定静帧数量默认三联；不要因转视频就擅自扩成九镜。

默认横向 2.39:1；21:9 严格比例为 7:3，并非 2.39:1。用户指定精确比例时保留该比例，检查生成与拼版尺寸；不要拉伸。视频画幅按选定后端能力适配，裁切需要保留叙事关键区域。

遵守用户指定后端。指定官方内置 Image Gen 时不得静默切到马良或其他服务；图像工具不是视频生成器。后端未知不妨碍编写中立视频提示词，但不能虚构 API 参数或已支持的控制功能。

## 2. 剧情与参考角色

多镜故事先读 [story-state-continuity.md](references/story-state-continuity.md)。九镜另读 [nine-shot-story-protocol-v3.md](references/nine-shot-story-protocol-v3.md)。

- 完整故事或已指定镜头：默认忠实分镜，保留事件、顺序、关系和结局。
- 一句开放命题：可原创，区分用户事实与新增设计。
- 三联扩九镜：优先补动作阶段、接近过程、视线与环境，不强加反转、牺牲或开放结局。
- 对每张输入标记用途：灵感 / 画风 / 人物 / 场景 / 产品 / 剧情锚帧；可多角色，但要写清保留范围。
- “只抽取灵感”的规则不能覆盖用户要求还原的资产。已批准的剧情锚帧不能被风格模板改写。

要求保留参考画风、已有校准帧或纠正画风漂移时，读 [style-reference-fidelity.md](references/style-reference-fidelity.md)。区分“参考不作为成片一帧”和“参考不得输入生成”，不要把前者误读成后者。

资产、新机位或空间连续性任务读 [asset-space-protocol.md](references/asset-space-protocol.md)。把未知空间明确为未知，不把推测伪装成三维测量。

## 3. 电影感决策

每镜确定一个主要事件、观看立场和信息落点；微动作、停顿、观察都可以成立，不必制造冲突。先问观众此刻应知道什么，再决定机位、景别和遮挡。

用户明确限制景别（如“不要特写，以场景和动作关系为主”）时，将它写入镜头账本；不要为了精致或镜头多样性插入违反限制的眼睛、手部或物件特写。

- 构图由关系产生：距离、亲密、阻隔、等待、权力或观察，而非套“远景—主观—眼部特写”。
- 视线流量：从哪里进入，被什么引导，落在什么关键证据上。不是每镜都必须复杂。
- 色彩来自服装、建筑、天气和光源。先锁综合色与主光源逻辑，不强制每个故事拥有固定数量的颜色。
- 光学与材质：可信曝光、自然皮肤、局部柔化、适度颗粒。避免无动机的 HDR、塑料皮肤、霓虹、粒子与全局色散。
- 全段安排景别和信息密度的节奏，保留必要的正反打、重复构图和普通过渡镜。不要强迫相邻镜头每次改变四项。
- 光源在世界中的位置连续；换机位可改变屏幕上的光照方向，不等于真实灯位移动。

## 4. 连续性：身份与状态分开

建立轻量 Continuity Bible，只重复与本镜有关的事实：

    世界：时代、时间、地点、可见结构、光源逻辑、媒介
    身份：角色 ID、少量稳定外貌/服装锚点、关系
    实体：关键道具 ID、数量、外观；不要把可转移物件当永久身份锚点
    状态：每镜的持有人、位置、开合/损坏、动作阶段、可见性；化形故事另记意象/半成形/可辨实体
    证据：计划状态与实际图像观察分开记录

相机、腕带、伞等被交付后，原持有人不能因“身份连续”自动再带一份。被遮挡/画外不等于不存在；映像不等于新增实体。剧情允许的归还、修复、闪回需要明确事件依据。

生成前建立镜头账本：

    镜号 | 来源节拍 | 功能 | 镜前→主要事件→镜后 | 机位与轴线 | 可见证据 | 依赖镜号

静帧只代表动作某一阶段；只有实际验收通过的状态才进入下游参考。不要凭提示词描述宣布动作已经生成成功。

## 5. 空间与参考输入

场景资产分“看得见的事实 / 有依据的推测 / 未知区域”。将世界位置、人物动作轴与屏幕左右分开。

每镜确定：摄影机可站区域、拍向、景别、必要锚点、遮挡、动作可达性，以及会暴露的未知空间。单图没有可信背面时，先采用保守机位；大幅反拍或环绕需要补视图，或明确为用户接受的空间扩展。

人物比例结合姿态、深度、地面接触和同深度参照检查，不固定像素大小。固定窗、门、产品不能因换机位被复制或搬移。

参考输入按角色选择：画风参考、身份参考、空间参考、当前状态参考。少量必要参考优于不加选择地全部输入。原始参考可支持画风/身份/空间，但不能覆盖后续已发生的状态变化；也不能只引用上一张而累积错误。

## 6. 静帧提示词

每个镜头独立生成，禁止让模型直接画三联、九宫格或分镜表。生成后外部拼版，保留可单独替换的源图。

图像提示词顺序：

1. 单帧、媒介与明确画幅。
2. 本镜相关的身份、空间和当前状态。
3. 本镜动作阶段及关键证据。
4. 摄影机实体位置、拍向、景别、透视意图。
5. 决定性前/中/背景信息。
6. 光源、综合色、有限的成像特征。
7. 与后端相容的精简排除项。

真人基底按需使用，不全堆叠：

> standalone live-action film still, practical location, natural skin texture, soft highlight roll-off, restrained production design, subtle uneven grain

不要把静帧负面词、角色长描述或“焦段标签”原封不动搬到图生视频。焦段文字表达意图，不证明后端精确执行了光学参数。

## 7. 视频动作与运镜

用户要视频提示词或实际视频时，必须读 [video-motion-protocol.md](references/video-motion-protocol.md)。只有需要写法示例时再读 [video-prompt-examples.md](references/video-prompt-examples.md)。

每镜交付“中文导演控制卡 + 可复制短提示词”，语言服从用户要求。导演卡管理首尾状态、时间、运动和衔接；短提示词仅包含执行所需的可见动作与摄影机行为，不照搬整张卡。

关键约束：

- 先判断输入图是动作首帧、中点、结束还是构图参考，再决定从哪里开始动。
- 人物移动、摄影机位移、转动、焦距变化和拉焦分别描述，不能相互冒充。
- 默认一段一个主要事件、一个主要运镜；固定镜头也成立。复杂长镜头仅在需要时设计。
- 明确机位运动的参照物、方向、终点构图和停止条件，避免“高级运镜”之类抽象指令。
- 九镜通常是九段独立片段；剪辑切换不是摄影机穿墙移动，下一镜首帧不自动成为上一镜尾帧。
- 设计时长与实际生成时长分开；没有对应控制接口时，不承诺精确到米、角度、帧或秒的执行。
- 未生成视频只能标“提示词已检查，运动未验证”。

## 8. 编排、返工与记录

可按三镜组织队列，但先验收关键状态变化镜，再生成依赖它的镜头。不要机械地用第一张初态图指导所有后续镜头。

每次记录镜号、修订、精确提示、输入参考及角色、返回路径、计划与观察状态。若工具提供模型版本/种子也记录；不得编造。顺序不能只凭修改时间推断。

失败时定位原因：指令矛盾 / 后端未遵从 / 参考状态过时 / 能力不足。只修相应镜头并复核下游依赖。默认同镜最多自动定向补跑两次；仍失败就报告未通过项和所需补充，不无限重试。用户另定预算时遵从。

遇到安全拦截先检查请求是否允许；不要通过隐去核心事实绕过限制。只有原请求本身允许且替代表达仍忠实时才尝试合规改写；需要改变核心剧情就说明并询问。

九镜拼版使用现有 [compose-nine-shot-storyboard.ps1](scripts/compose-nine-shot-storyboard.ps1)，先核对参数与目标比例。保留 9 张源图、3 张纵向三联和 1 张接触表；默认黑色小间隔、无附加文字、无拉伸。输出到用户规定目录，没有规定则用任务专用目录。

附带脚本使用 PowerShell 与 System.Drawing，优先在 Windows 执行；其他环境使用可用的等效工具完成同样拼版，不更换已成功的源图。

## 9. 验收：先事实，后美术

硬门槛：原剧情关键事实、身份与必见角色、道具数量/归属、指定画风/媒介、空间拓扑、动作可达性、输入首帧相容性、文件完整性。用户要求可辨角色时，只有影子或烟雾轮廓不能算完成；具象化的身份与来源分别验收。

结果记为“通过 / 失败 / 无法判断”，附可见证据；看不清不能算通过。硬门槛失败不得以审美总分抵消，也不宣称“已解决”。交付草稿时明确标出未通过项。

- 跨镜既查相邻衔接，也查远距离因果，例如第 5 镜留下腕带后，第 9 镜手腕仍应为空。
- 还原检查用“原故事事实→镜头证据”映射；必要时不看说明复述故事。不要把看过答案的自检称为盲测。
- 视频检查首、中、尾及动作关键时刻，区分主体运动与相机运动；静帧不能证明“慢半拍”等时间事实。
- 事实通过后评价构图、色彩、节奏、材质与媒介；不为不同题材强设同一镜头数量配额。
- 只作提示词/规则检查时，不报图像或视频成功率。
