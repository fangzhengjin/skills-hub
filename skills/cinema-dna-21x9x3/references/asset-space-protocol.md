# 资产与空间协议｜3.1

用于场景/人物/产品资产、连续机位、比例或轴线检查。目的不是把所有细节写死，而是保留用户指定的世界事实。

## 输入角色

| 角色 | 保留范围 | 可变化范围 |
|---|---|---|
| 灵感参考 | 用户选择的构图/配色/题材方法 | 未指定要还原的具体人物、物件与剧情 |
| 画风参考 | 指定媒介、线条、色块、明暗与纹理 | 当前剧情允许的构图、动作和机位 |
| 人物资产 | 身份、指定造型、体态关系 | 合乎剧情的表情与动作 |
| 场景资产 | 可见建筑、门窗、家具、产品数量与拓扑 | 可行机位、人物调度、事件 |
| 产品资产 | 轮廓、结构、材质与指定标识 | 有视图依据的角度及环境 |
| 剧情锚帧 | 已确认的事件与状态 | 不改写锚点的前后过渡 |

一张图可有多种角色。只抽取灵感与必须保留资产是不同任务；明确“根据这张空间做分镜”时，不用原创规则重建房间。参考之间矛盾时说明冲突，不能任意挑一个当事实。

## 空间证据

建立最小空间表，而非虚构完整三维模型：

```text
可见：有图像证据的位置、相邻、遮挡、固定结构
推测：深度范围、可通行区域、墙面延伸；附依据和置信度
未知：图外背面、隐藏开口、精确尺寸、产品背面
坐标：以固定墙/门/参考机位定义局部坐标；不把屏幕左右当世界坐标
轴线：人物对话/交互或行走的主轴；与建筑对称轴区分
尺度：姿态、深度、地面接触与同深度参照；实测尺寸仅来自资料
```

例如浴室资产可确认参考视角左侧淋浴区、后方窗与浴缸、右侧台盆；这不证明镜头背后还有一扇门。反拍前问该机位到底看得见什么，不让原窗、原电梯在相反墙上再出现一次。

## 每镜摄影机卡

- 起点：可站区域、拍向、高度等级、主体距离关系、景别。
- 轴线：处于当前动作轴哪侧；主体的屏幕左右和视线如何投影。
- 必见锚点：少量足以认出原空间的结构。
- 遮挡：按机位哪些应在前、哪些应消失于画外/被挡。
- 可达性：人物走路路径、手臂触及、门开启范围、相机运动是否穿过实体。
- 风险：将暴露多少未知空间、是否需要补参考或重新建立空间。

单图资产默认先用同侧有限角度、景别与高度变化。用户明确要大幅反拍/环绕时，说明缺失依据，提供补视图/平面图/三维模型方案；未获信息可先交付有风险标记的导演设计，不宣称已精确还原背面。不要静默取消用户指定的运镜。

## 轴线与比例

世界结构固定，屏幕位置随机位改变。维持屏幕左右不是空间正确的充分条件；左右变化也不是越轴的唯一证据。

不同人物组合可形成不同轴线。换轴用建立镜头、清晰的连续移动或明确方向证据重新定向；有意失衡可采用但需要说明观看目的，不把“导演感”当无条件借口。

比例检查优先看脚/膝落地、坐姿支撑、手与道具接触、同深度参照、前后遮挡；不要用不同景别下人物像素高度来判定缩放错误。原素材无精确尺寸时使用相对关系，焦段数字不能代替这些检查。

镜面/玻璃额外标注真实空间与映像空间、对应对象、观察方向；异常反射仅按原剧情例外，不当作普通空间错误的解释。

## 参考与验收

分开选择画风、身份、空间、状态参考。要求保留原画风时另读 [style-reference-fidelity.md](style-reference-fidelity.md)，不要将画风保真误当成复用原构图。参考只能锁它负责的事实，不能要求既复用原机位又完全换机位。关键状态变化后的参考不能被初始图覆盖。

检查实际画面：门窗数量、墙面相邻、人物脚点、道具可达性、遮挡、运动路径。结果不清楚就标无法判断。只有文字方案时检验的是设计自洽，不是三维还原已成功。
