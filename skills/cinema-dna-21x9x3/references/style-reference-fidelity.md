# 画风参考保真｜3.1.1

保留上传图画风、沿用已批准校准帧，或修复画风漂移时读取。没有参考且用户要求自由设计时，不额外制造风格校准任务。

## 参考合同

区分四种要求：

- 只借配色/构图：只继承用户选定的维度，不顺带锁人物、场景或笔触。
- 保留画风：锁媒介、线条、色块、明暗组织与纹理；剧情、机位和动作可以重新设计。
- 保留人物/场景：同时遵守对应身份与空间事实；不能拿“原创”作为换脸、换场景的理由。
- 不要把参考当某一帧：所有目标镜头重新生成，不裁切或拼入原图；这不等于禁止把原图作为工具参考。用户若明确禁止上传/输入原图，则不传入工具，并说明文字转译的保真限制。

先看实际图像。工具支持图像参考且符合用户允许用途时，将相关原图真正传入，并记录参考顺序与角色；不能只写“完全一致”却不提供可用参考。缺失输入或后端不支持时如实说明，不用别的画风顶替。

## 小而明确的风格锁

记录真正影响辨识的几项：

    媒介：摄影 / 平涂手绘 / 水彩 / 版画 / 三维……
    线条：粗细、边缘硬软、轮廓与内部细节密度
    色与明暗：主色块、明度分布、留白/暗部面积，而非只抄两个色名
    纹理：纸、颗粒、干刷等落在哪里，是否局部而非全局滤镜
    人物：需要保留的身份、形体、服装；与画风字段分开

例如原图是黑红平涂与少量硬线，不能换成黄褐色细密蚀刻山水后仍称“同画风”。这只是保真判断示例，不要求其他题材使用黑红色。

“电影感”主要通过构图、调度和剪辑获得，不授权把手绘改真人、加写实毛孔，或强加柔光、颗粒和光学虚化。非摄影媒介可用焦段/机位语言表达观看意图，但纹理与空间表现服从原媒介。

## 从被认可的画面继续

- 用户认可的校准图锁定它被认可的维度；若同时认可它作为故事镜头，则保留该镜，不为凑“全新”数量再画一次。
- 若仅认可画风而画面状态与故事冲突，作为风格参考，不自动列入最终镜数。
- 曾发生画风漂移或高风险多镜任务，可先生成计划内一个镜头作样片，自检后继续；不默认额外生成整套定妆图或在每镜强制等待批准。
- 风格参考、身份参考和当前状态参考分开。多角色群像使用少量已验收的角色帧；原图中未被要求继承的人物/道具不自动进入当前镜头。
- 不只链式引用上一张。后续仍按需要回看/输入原始风格锚点，防止逐镜累积偏移；也不把已失败的画风样片当新标准。

## 定向修正

定位到底是媒介、笔触、综合色、身份还是事件错误，再修对应部分。修耙齿、服装或手部时明确其他内容保持，但只有图像复查后才能声称保持成功。

全组画风错了，可以在用户要求范围内重做全组；单镜局部错误只修该镜，并复核依赖它的下游。遵守主技能的补跑上限。

验收分别记“风格是否匹配”“角色是否可辨”“事件是否成立”。配色相似不能抵消人物缺失；角色明确也不能抵消画风更换。未获用户审美确认时，称自检，不冒充用户认可。
