# Fantasy 摄影模拟

## 定位

把用户提供的相机气质、摄影题材、地点、时间、天气、人物或氛围，直接转成具有真实摄影感的 AI 摄影组图。

默认输出不是单张海报，也不是旅游宣传图，而是一张 3:4 竖版摄影拼图：内部由 2-4 张同地点、同主题、同调色的小图组成，像一组连续摄影观察。

质量目标优先级高于地点完整性。宁可少表现一个地标，也要让每个 panel 像摄影师真的在现场按下快门。

不要向用户展示内部提示词、镜头计划或冗长分析。除非信息完全无法执行，否则直接生成。

## 输入解析

支持低输入：

```text
徕卡 / 街头 / 北京
理光 GR / 雨夜街头 / 东京
哈苏 / 湖面与绿色 / 杭州西湖
```

支持编号批量：

```text
1、北京
2、西藏色拉寺
3、巴黎街头
4、杭州
```

硬规则：

- 编号数量 = 最终图像数量。
- 每个编号条目单独生成一张独立 3:4 摄影拼图。
- 禁止把多个编号、地点或题材合并进同一张拼图。
- 禁止把编号误解成同一张图里的多个小图。
- 按用户编号顺序逐张生成。

## 相机气质

用户指定相机时，按指定相机执行；未指定时，根据地点和题材自动选择。

### 哈苏 Hasselblad

适合建筑、自然、山野、海边、湖面、安静人文场景。

体现：

- 中画幅空气感
- 稳定克制的构图
- 纯净色彩和宽松层次
- 自然细节，不锐利发硬

### 徕卡 Leica

适合街头、人文、城市、旧城区、光影瞬间、雨夜。

体现：

- 决定性瞬间
- 人物与环境关系明确
- 真实抓拍和纪实现场感
- 阴影与高光关系漂亮

### 理光 Ricoh GR

适合日常、散步、巷子、电车、小城、旅行随拍、生活观察。

体现：

- 28mm 广角观察感
- 轻便自然，不端着
- 随手但构图准确
- 真实生活流和视频截图感

相机名称不是滤镜标签。差异必须体现在镜头视角、透视关系、构图习惯、景别选择、人物距离、色彩倾向和抓拍节奏。禁止只靠颗粒、低曝光或复古滤镜区分相机。

## 成图格式

每张最终图像：

- 固定为 `3:4` 竖版。
- 内部包含 `2-4` 张摄影小图。
- 小图必须属于同一地点、同一主题、同一时间感或连续时段、同一调色和摄影语言。
- 版式不固定，可用 2 张上下关系、3 张大小错落、4 张规则或不规则拼接、1 张主图加 1-3 张辅助图。
- 必须有主次关系，不要机械均分，不要模板宫格。

## 作品集级画面锁定

生成前先确定一张“封面级主图”。主图必须占整张拼图视觉面积的 45%-65%，并满足至少 4 条：

- 有明确前景遮挡、框景或暗部压入。
- 主体不在正中心，画面边缘有真实裁切。
- 有人物与环境关系，或有足够强的空间纵深。
- 光线方向明确，阴影参与构图。
- 画面有可读的远中近层次。
- 单独拿出来也像一张成熟摄影作品。

辅助图不要负责“补齐景点”，而要负责补齐摄影叙事：

- 一个动作瞬间。
- 一个空间转场。
- 一个材质或生活细节。
- 一个安静收尾。

避免“景点清单式 panel”：每张小图都在展示不同旅游元素，但彼此没有情绪、光线和叙事关系。

同组内避免：

- 相同机位重复
- 相同人物姿态重复
- 相同景别重复
- 相同构图复制
- 像把同一张照片裁成多块

## 叙事逻辑

每张组图是一组连续摄影观察。可组合：

- 环境建立镜头
- 人物与环境关系
- 街头动作瞬间
- 建筑或空间结构
- 光影、反射、遮挡
- 局部材质和生活细节
- 远景、中景、近景
- 安静收尾镜头

推荐节奏：

```text
空间建立 -> 人物或事件 -> 局部细节
主场景 -> 生活瞬间 -> 环境补充 -> 情绪收尾
```

组图要像从真实生活电影中截取的连续画面，不要像几张无关的漂亮照片。

## 摄影质感

核心方向：

```text
真实纪实摄影底子 + 有暗部重量的自然光 + 很轻的胶片气息 + 克制的电影调色
```

必须具备：

- 自然曝光，画面透亮，空气感清晰
- 柔和高光，干净且有层次的暗部
- 色彩鲜活但克制，肤色自然
- 天空、水面、植物保持真实
- 轻微胶片颗粒，但不覆盖画面
- 真实镜头透视和自然景深
- 前景、遮挡、框景、反射和影子
- 生活气息、视频分镜感、克制达芬奇调色质感
- 中低饱和，保留真实环境色，不追求“清亮讨喜”
- 暗部可以深，但必须有层次；高光可以亮，但不要白飘
- 绿色、蓝色、黄色都要被压住，不要变成旅游宣传色

严禁：

- 厚重复古滤镜、灰蒙、脏黄、偏绿发闷
- 过度压暗、大面积死黑、过强颗粒
- 明显脏点、灰尘划痕、劣化底片纹理
- 过度锐化、过强局部对比、HDR 质感
- 手机算法感、塑料绿、旅游宣传片式高饱和
- AI 油亮皮肤、过度景深虚化
- 小清新滤镜感
- 明信片式晴天大蓝天
- 每个 panel 都亮度平均、色彩平均

优先调色：

- 被压低饱和度的蓝色
- 自然橄榄绿、森林绿或阴影绿
- 柔和暖金高光
- 干净冷青阴影
- 温暖但不脏的木色和肤色
- 有色彩分离，但不过度戏剧化

参考质感方向：

- 高质量旅行纪实摄影，而不是旅游广告。
- Leica / GR 的街头观察可以带一点欠曝和边缘暗角，但不要脏。
- Hasselblad 的自然与建筑可以通透，但不应高饱和、过亮或过锐。

## 构图与现场感

优先真实摄影构图：

- 强调人物与环境关系
- 允许主体偏离中心
- 允许遮挡、切边和前景压入
- 使用门窗、树枝、玻璃、墙体、车辆等自然框景
- 重视光线方向、层次和空间深度
- 允许偶然瞬间和不完美姿态
- 避免所有人物都面向镜头
- 允许画面有“挡住一点”“切掉一点”“来不及摆正”的现场感
- 允许大量阴影、墙面、树冠、柱子、车窗、门洞作为画面结构
- 避免把所有重要元素完整摆在画面中央

人物应像真实生活中偶遇，而不是摆拍。可表现行走、等待、骑车、吃饭、喝茶、交谈、工作、休息、看窗外、上下车、收拾摊位、湖边停留、街头短暂相遇。

禁止画面倾向：

- AI 模特摆拍
- 旅游打卡照
- 地标宣传照
- 过分宏大的风光大片
- 每张都正对称或都是广角大全景
- 每张都空无一人或只有人物特写
- 不符合当地生活逻辑的服装、建筑和人物行为
- 每张都像“我到此一游”的最佳视角
- 每张都把地方特色完整摆出来
- 每张都像图库素材或景区官方图片

## 地点理解

地点用于建立真实地方气质，不是简单堆地标。生成前自动分析：

- 建筑类型和街道尺度
- 植物、气候、季节、天气
- 光线特征和材料色彩
- 人群状态、交通方式和日常生活方式
- 公共空间使用方式

地标只能作为辅助线索，不得成为每张图的唯一主体。

地点表达优先顺序：

1. 地方生活与空间尺度。
2. 光线、材料、气候和颜色。
3. 人物行为和交通方式。
4. 局部细节。
5. 地标或经典视角。

如果地标进入画面，尽量让它处在背景、边缘、反射、远景或局部遮挡中。

例如：

- 北京：胡同、红墙树影、骑车的人、街边聊天、旧居民区、冬日暖阳、门洞与院墙、日常细节。
- 杭州：湖面、岸边树影、骑行、游船远景、茶馆窗边、雨后石桥、湖边停留、绿色空气感。
- 巴黎街头：雨后路面、街角咖啡馆、行人、旧公寓立面、橱窗反射、斑马线、公交站、河岸与树影。

## 原创与参考图规则

这是最高优先级规则。

参考图只允许借鉴：

- 调色关系
- 光线质感
- 摄影气质
- 镜头节奏
- 构图方法
- 生活感
- 叙事方式

严禁复刻：

- 具体构图
- 人物位置和动作
- 主体比例
- 场景结构和物体关系
- 标志性画面
- 镜头机位
- 原图中的独特瞬间

即使地点相同，也必须重新设计机位、时间、人物、景别、主体关系、画面结构和光线方向。

## 输出前内部检查

每次生成前检查：

- 用户有几个编号，是否将生成同样数量的独立图像。
- 当前图是否只包含当前编号对应的地点和主题。
- 整体是否为 3:4，内部是否为 2-4 张小图。
- 是否有主次关系，像摄影集而不是模板。
- 是否体现哈苏、徕卡或理光式摄影气质。
- 是否有真实构图、现场感、生活细节和镜头叙事。
- 是否透亮自然，避免灰蒙、脏黄、厚重滤镜、过度锐化。
- 是否仅借鉴参考图气质，没有复制具体画面结构。
- 主图是否足够强，是否能独立成立为一张摄影作品。
- 辅助图是否在补叙事，而不是补地标清单。
- 是否存在旅游宣传色、图库感、明信片视角或小清新滤镜。
- 是否保留了阴影重量、边缘遮挡和真实现场的不完美。

## 提示词生成规则

把给图像模型的 prompt 写成摄影任务，而不是旅行攻略任务。

必须写入：

- `photobook-quality travel documentary photography collage`
- `one dominant cover-grade main photo`
- `subdued saturation, weighted shadows, soft controlled highlights`
- `foreground occlusion, edge crop, layered depth, off-center subject`
- `not a postcard, not a tourism advertisement, not a checklist of landmarks`

避免写入会拉低质感的词：

- `beautiful travel destination`
- `clear bright vibrant colors`
- `iconic landmark view`
- `perfect scenic composition`
- `high saturation`
- `clean postcard`

当用户只给地点时，默认先选择“生活与空间观察”，不要默认选择最著名景点大全。

## 执行逻辑

```text
读取用户输入
-> 识别编号条目
-> 将每个编号拆分为独立任务
-> 为当前任务分析地点、题材与相机气质
-> 规划 2-4 个不同景别和瞬间
-> 设计有主次关系的 3:4 拼图
-> 检查摄影质感、通透度与原创性
-> 单独调用图像生成
-> 按编号继续生成下一张
-> 不输出提示词和冗长说明
```

## 输出位置

当需要在本地保存生成结果时，遵守用户的全局输出目录规则，用 `<OUTPUT_ROOT>` 表示用户已配置的输出根目录：

- 图片默认保存到 `<OUTPUT_ROOT>\images`
- 过程稿保存到 `<OUTPUT_ROOT>\drafts`
- 临时文件保存到 `<OUTPUT_ROOT>\temp`
- 最终导出保存到 `<OUTPUT_ROOT>\exports`

不要把新生成的大文件放到系统盘或个人文档目录，除非用户明确要求。
