# Composition Patterns · 构图模式库

先理解内容，再选构图。用**二轴分析** + **创意生成法**，输出 Shot Config。

---

## Step 2 决策流程

| 层级 | 谁做 | 做什么 |
|------|------|--------|
| **硬规则** | Skill 变量 | `$RATIO` / `$IP` / `$COUNT` 等；用户明确指定时优先 |
| **中度规则** | 本文件流程 | 二轴分析 → 创意生成法八步 → 选构图 → 输出 Shot Config |
| **软判断** | 大模型 | 隐喻发明、物件选择、标注词、局部配色、是否合库 |

### 1. 二轴分析

**结构轴** — 这张图传达什么结构？（决定构图库匹配）

单点澄清 / 对比 / 路径序列 / 情绪状态 / 环境隐喻 / 信息聚焦

**互补轴** — 图与文字/口播如何分工？

- 图承担：骨架、隐喻、情绪、关键节点
- 文字/口播承担：论证、细节、故事
- 据此决定 hierarchy 强弱；标注 2–5 个，只标必要信息

### 2. 输出 Shot Config

按 `shot-config.md` 落盘。多张图时按段落或论点拆，每张只回答「这一段最想让人记住的一个判断」。  
落盘前对每张执行 **视觉承诺**（**必读** `visual-promise.md`）+ **密度档 / 阅读动线**（见下方「阅读动线语法」）。不进 STYLE_DNA；承诺细则不在此重复。

## 创意生成法（必走，优先于查表）

### 八步（含视觉承诺 + 动线）

1. **核心信息**：这张图要让人理解什么判断、结果、关系或情绪？
2. **信息类型**：结果、对比、路径、状态、风险、选择、转折、承接。
3. **物件表意**：从锚定句/段落抽出 **2–5 个可画名词**；主载体须从中派生，禁泛化替代。若属专业域 → 先按 `visual-promise.md` §C 抽**域物件**再写入物件表意（域物件优先于万能隐喻）。
4. **主载体 + 辅助物件 + 信息分工**：主载体 1 个；辅助 1–3 个；标明各物件角色。禁默认象征物（无原文语义时）。`$IP=none` 且需演员 → 读 `ip/none.md`。有 IP 时：专业域下 IP **后置导游**，不抢专业物件。
5. **视觉承诺字段**：按 `visual-promise.md` 填写（结构 / 外参 / 域物件 / 意象·无）；硬物件结构见该文件 §A。
6. **密度档 + 阅读动线（T3′）**：填 `density` + **阅读顺序**一句（见「阅读动线语法」）。`scenic` **强制**更强焦点与路径。
7. **故事动线**：A→B→C 与阅读顺序对齐；有 IP 参与（动作库；路径序列读「序列图导游」）。
8. **标注对齐**：默认写 2–5 个标注词并挂动线节点；**禁真名 ≠ 禁标注**（纪律 **`visual-promise.md` §E**）。禁止为外参/scenic/后期叠字自行清空标注；仅用户明示免标才写「无（用户要求）」。

## 阅读动线语法（T3′ · 本文件为 SSOT）

> 「碎」= **无阅读语法 / 无主路径**，不是标注个数多。  
> 满景（scenic）是**放大器**，不是病因；**禁止**用「禁满景」或只砍标注数当根治。  
> 默认阅读习惯多为上→下、左→右，但**不写死进宪法**；必须在 shot-config 写出当次「阅读顺序」。叙事可故意右下回收到左上，只要写清且画面能跟。

### 密度档 `density`

| 档 | 含义 | 典型 | 动线门禁 |
|----|------|------|----------|
| `sparse` | 白底/疏景物 | quirky 默认 | 标准：焦点 + 路径/序号任一可读 |
| `medium` | 中等场景 | 室内半景 | 标准动线 |
| `scenic` | 满景/旅行手帐页 | warm-storybook 户外·街景 | **强制**：① 唯一主焦点 ② 阅读顺序必填 ③ 主路径视觉权重大于装饰纹理 ④ 标注嵌节点，禁满景飘箭 |

**选档：** 风格允许满景且本张环境铺满 → 标 `scenic`（勿假装 sparse）。暖调旅行/海岸/骑楼默认按 scenic 自检。

### 每张必写「阅读顺序」

一句人话即可，例如：`焦点 Gimi → 左文档光 → 右肩标注` 或 `①门楼 ②骑楼进深 ③小吃摊 → Gimi`。  
3 秒内必须能按该顺序跟完「发生了什么」。

### 跨风格等价物（治本）

| quirky（疏景）常用 | scenic 必须有等价 |
|--------------------|-------------------|
| 白底分层 + 线权 | 光影/大小/景深分层，仍有**一个**最抢眼焦点 |
| 编号圈 ①②③ / 粗路径箭 | 褐笔路径、地面引导线、手势指向、或少量编号——**主路径权重要够** |
| 物件少而清 | 景物可多，但装饰不得与主路径等权 |

### 失败形态（scenic 高发）

- 标注箭头指空 / 多箭等权无主路径  
- 满纹理、无人能说「先看哪」  
- 只加标注个数或只改 STYLE_DNA 想治「碎」

### SUBJECT / COMPOSITION 提示（组装时用）

`scenic` 时在构图或 SUBJECT 末追加意涵（英文可意译）：  
`One primary focal point; clear reading order <阅读顺序>; supporting scenery lower contrast/size; labels attach to path nodes, not floating equally across the frame.`


### 参考池（须过 Step 3，不可盲套）

**物件灵感** — 信封、天平、蜡烛、弹簧、镜子、迷宫、梯子、水管、瓶子、门、沙漏、齿轮、线团、纸箱、秤、晾衣绳、开关、传送带、漏斗、筛子、插头、卡片、窗口、路标、图钉、印章、回退钮（非封闭列表，可自创）

**慎用象征**（仅原文有对应语义时）— 放大镜（审查/查找）、灯泡（灵感）、问号（显式疑问）、站牌（路标式步骤）

**有 IP 时的动作** — 读 `ip/{$IP}/ip.md`「动作库」；禁为凑热闹加与锚定句无关的动作

### 表达策略

| 信息类型 | 画面策略 |
|----------|----------|
| 结果 | 把最终状态画清楚，步骤只做辅助 |
| 对比 | 左右或上下对照，让差异一眼可见 |
| 路径 | 保留关键节点，用大小、位置、层次区分；箭头串联故事动线；见「序列构图语法」 |
| 状态 | 画出「卡住、松开、打开、变亮、变轻」等状态变化 |
| 风险 | 用原文具名物件 + 线稿改动/混乱动线表现问题；**不默认**放大镜/灯泡 |
| 承接 | 用连接、递交、桥、线、卡片表现关系 |

## 序列构图语法（结构轴 = 路径序列时必用）

**主路径 vs 异常分支**

| 类型 | 画法 | 标注 |
|------|------|------|
| **主路径** | 标题写「N 步」→ 画面只画 **N 个等权主节点**（①②③…） | 标注词对应主节点名 |
| **异常/坏状态** | 画在**最后一环内部**或小分支：好状态 → 变坏 → 动作 → 恢复 | 可标「改坏了」等，**不单独占第 N+1 站** |
| **回退/恢复** | 箭头：**坏状态或回退钮 → 存档点/好状态** | 禁止指向坏状态本身 |

**回退箭头语义（通用）**

- ✅ 改坏的文件 → 存档盒 / 干净文件 / 上一存档点  
- ✅ 回退钮 → 存档盒（动作入口）  
- ❌ 「回到存档」→ 指回「改坏了」  
- ❌ 主路径大箭头跳过坏状态，从第 2 步直连终点  

**序列逻辑构图**应写清：主路径几个节点、异常画在哪一环内部、回退箭头起止。

## 构图库（选一种即可）

**单主体居中** · 单点澄清  
一个主体置中，周围大量留白。适合核心结论、单一关键词。

**对比并置** · 对比  
左右两个对比元素（问题 vs 答案、旧 vs 新）。适合转变、before/after。

**行动中人物** · 情绪状态 / 路径  
角色处于动作过程中。强调过程、努力、成长。

**物件特写** · 单点澄清 / 信息聚焦  
一个放大的物件占画面主体，靠物件本身说话。

**环境暗示** · 环境隐喻 / 情绪状态  
角色极小，处于大环境中（迷宫、空旷场景）。适合困境、迷失、反思。

**图标级单主体** · 单点澄清  
超简洁视觉符号，四周大留白。适合单一关键词。

**隐喻场景 mini** · 环境隐喻  
极简场景，3 个元素以内，传达完整隐喻。

**序列逻辑** · 路径序列  
2–4 个主路径节点横向排列，编号圈①②③。异常 / 回退见「序列构图语法」。适合步骤、框架、方法论。

**情绪面孔** · 情绪状态  
放大的夸张表情或身体语言。

**信息聚焦** · 信息聚焦  
一个清晰视觉焦点承载核心信息，其他元素缩小做辅助。

**都不 fit？** 根据 `核心信息` 自定义 `{COMPOSITION_DESC}` 英文描述。
