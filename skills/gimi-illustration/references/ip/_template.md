## 合约槽位（每个 `{id}` 必须可回答）

| 槽 | 必填 | 落盘位置 |
|----|------|----------|
| `id` | ✅ | 目录名 `assets/ip/{id}/` · `references/ip/{id}/` |
| 设定图 | ✅ | `assets/ip/{id}/reference-character.png`（**落盘后一律全身 full**） |
| 锚点 3–6 | ✅ | `ip.md`「锚点」 |
| `{IP_STYLE_EXCEPTION}` | 按需 | 仅用户明确指定跨风格画法时写入 `ip.md`；不得从设定图或普通描述推断 |
| 气质一句话 | ✅ | `ip.md` 顶栏 |
| `{IP_DESC}` | ✅ | `ip.md`「填入 `{IP_DESC}`」 |
| `{IP_STYLE_ADAPT}` | 可选 | 有易串色/走形部位才写；无则整节省略或留空 |
| 校准图 | 尽量 | `assets/ip/{id}/examples/{$STYLE}/`（**按风格分子目录**） |
| QA 失败信号 | ✅ | 由锚点生成，写在本 `ip.md` |
| 动作库 | ✅ | `ip.md`「动作库」；可按气质删减，禁默认放大镜 |
| 序列图导游 | ✅ | `ip.md`「序列图导游」；结构轴 = 路径序列时由 composition 读取 |

### 双图分工（一句）

```
设定图 → 「这是谁」（全身锚点、配色、比例）；跨 $STYLE 复用
校准图 → 「用当前风格配图时长什么样」（读 `styles/{$STYLE}.md` 的 0.4 样板镜）
风格规则 → styles/{$STYLE}.md（STYLE_DNA）；校准生成时必须载入
```

### 参考协议

```
当前 `$STYLE` 有校准图 → $REF_MODE=dual（设定图 + 1 张该校准图）
当前 `$STYLE` 无校准图 → $REF_MODE=lazy；只补 0.4，不进正式配图
已有 IP 的正式配图不允许 single；用户催图也须先确认当前风格样板
```

**多风格（v3.0 启用细则）：** 配图时若 `examples/{$STYLE}/` 为空 / 缺文件 → **lazy 补 0.4**（只跑校准，设定图复用）；**确认前不 dual，且不得写 `shot-config.md` 或正式图**。已有 IP 的正式图一律 dual，用户催图 / 说跳过样板也不降级；说明需先确认样板才能正式配图。

lazy 开场（人话）：「这个画风下还没有你的样板，我先按「{display_name}」画一张给你看——通过后我们再正式配图。」

## 设定图可用性（画风不限）

**0.1 收用户附图** → 判断输入为 **全身** 或 **胸像/半身**（仅录入态，不落盘字段）。

**全身输入（可进入 0.2；不得跳过 0.2）**

1. 正面全身（头到脚）
2. 锚点可辨；单角色；干净背景更佳
3. 附图可作设定稿候选；**首轮禁止生图**，须先过 0.2 文字确认

**胸像/半身输入（确认后再扩全身设定）**

1. 正面、锚点可辨、单角色
2. **不得**直接把胸像落盘为 `reference-character.png`
3. **首轮禁止生图**；方案里说明「确认后立刻扩全身设定」；用户确认后再跑 0.2b

任一档不合格 → 指出缺什么，**不落盘**。

## Step 0 · 填槽流程（协议层）

触发：`自定义 IP` / `录入 IP` / `上传形象` / `新建 IP`（用户附图即可；**不必写 Step 编号**）

**Step 0 全程关闭 Quick Mode**（不得「出图即走」）。

### Step 0 硬门禁（入口 · 路由 · 出图后）

> **方案 A（4.7）：** 半身/全身首轮**统一零生图**——关掉「半身可同轮生图」开口，杜绝与防 ImageGen 抢跑互相打架。

**A. 入口（第一轮 · 半身/全身相同）**

- **必须**：0.1 判定 + 0.2 形象方案（id / 气质 / 锚点）+ 用户层收尾问
- **首轮禁止调用任何生图工具**（含 `image_gen` / `GenerateImage` / ImageGen）
- **一律禁止**：竖版海报 / 杂志风 / 扁平矢量成稿 / 风格迁移海报 / 文章配图
- 半身：方案中说明「你传的是半身；确认后立刻扩全身设定（只锁身份，还不是怪诞手绘）」——**本轮不出图**
- 全身：附图作设定稿候选；**不得**因「已是全身」跳过 0.2 直接生图
- 自检：首轮已出图 → **路由错误**，停生图，回到 0.2

**B. 路由（至 0.5 完成）**

- 禁止 Step 1–5；禁止任何 `shot-config.md`；禁止 `composition-patterns` 正式策略
- 生图仅允许在 **0.2 确认之后**：半身 0.2b 设定稿 / 0.4 校准

**C. 出图后**

- 生图工具返回后，**同轮**仍须追加用户层收尾问；**图 ≠ 闭合**（0.5 除外）

**D. 0.2b 画面（半身 · 仅确认后）**

- 头到脚、中性、无场景无标注；非全身 → 不展示，重生

```
0.1 可用性检查（全身 / 半身）
0.2 形象方案（半身/全身均须；首轮禁止生图）→ 一问确认
      确认后：
      半身 → 0.2b 生成全身设定稿 →「设定图对吗？」
      全身 → 附图落盘，跳过 0.2b → 0.3
0.3 落盘 reference-character.png（full）+ ip.md（对用户尽量静默）
0.4 标准风格样板镜 → 问「像吗？」
      像 → dual → 0.5 告知可用
      不像 / 想调整 → 重跑 0.4；用户暂不确认 → 停在样板态，不交付正式配图
```

原则：不问「要不要校准」；问「像不像」。校准不通过 / 未确认时，IP 可保留为录入中，但**不可**用于正式配图。
**半身与全身共用同一入口闸（首轮零生图）；差别仅在确认后是否跑 0.2b。**

### 用户层话术（唯一合法收尾 · 必须中文）

> 对用户不暴露 Step 编号。风格称当前 `$STYLE` 的 `display_name`（录入默认多为「怪诞手绘」）。

| 场景 | 最后一句 |
|------|----------|
| 0.2（半身） | 「你传的是半身。确认后我会立刻扩全身设定。按这个形象方案录入吗？」 |
| 0.2（全身） | 「附图将作为全身设定稿候选。按这个形象方案录入吗？」 |
| 0.2b | 「这是全身设定稿（只锁身份，还不是「{display_name}」风格）。设定图对吗？」 |
| 0.4 | 「这是该 IP 用「{display_name}」风格配图时的样子（非正式成稿）。像吗？」 |
| 0.5 | 「录入完成。配图时说『用我的 {名}』或 `$IP={id}` 即可。」 |

可选进度（半身）：「录入进度：确认方案 → 确认设定 → 确认风格样板」  
可选进度（全身）：「录入进度：确认方案 → 确认风格样板」

**禁止收尾：**「请查看」「已处理完毕」「正在渲染竖版海报」等无确认问句 → 未闭合 / 路由错误。

### 0.4 门禁（硬）

1. **生成**：必须载入 `ip.md` 的 `{IP_DESC}` / `{IP_STYLE_ADAPT}`、仅用户明确指定时的 `{IP_STYLE_EXCEPTION}`，以及 `styles/{$STYLE}.md` 的 `{STYLE_DNA}` + `{STYLE_ADAPT}`
2. **画面**：按 `styles/{$STYLE}.md`「Step 0.4 生成」的**标准风格样板镜**；角色全身可见；**禁止**文章主题、shot-config 物件、标题、编号步骤（默认；除非该风格 0.4 明文另定）
3. **用途**：预览该 IP 进入正式配图 pipeline 时、当前 `display_name` 下的样子；**非正式配图**；学本风格质感与色纪律，**不学** gimi checklist 的避坑叙事标注
4. **闭合**：用户未答「像吗？」前，**禁止**进入配图 Step 1–5；**禁止**把正式配图当校准
5. **中断**：0.1–0.3 因平台限制改路径后，从 **0.4 重开**

### 标准风格样板镜（Tier 1 · 规格读当前 `$STYLE`）

| 项 | 规格 |
|----|------|
| 比例 / 角色 / 主题文案 / 物件清单 / 色纪律 | **全部以** `styles/{$STYLE}.md`「Step 0.4 生成」为准 |
| IP 层只保证 | 全身可见；禁止文章主题、shot-config 物件、标题、编号步骤（除非该风格 0.4 明文另定——默认禁止） |
| 必须载入 | `IP_DESC` + `IP_STYLE_ADAPT` + 仅用户明确指定时的 `IP_STYLE_EXCEPTION` + 该风格 `{STYLE_DNA}` / `{STYLE_ADAPT}` + 已确认设定图 |

与 gimi Tier 2：多主题选题库仍仅 gimi；自定义 IP **只用**当前 `$STYLE` 的样板镜节。  
**禁止**在本文件写死某一风格的色纪律（如软蓝/橙）；具体色方案只在 `styles/{$STYLE}.md`。

### 校准图入库 QA（5 项，全过才展示并问「像吗？」）

- [ ] 比例与全身（以当前风格 0.4 节为准；默认 16:9 全身）
- [ ] canonical 场景物件 2–4 个；**本风格**色纪律合格
- [ ] 无文章主题 / 标题 / shot 物件（默认）
- [ ] 质感符合当前 `$STYLE` 的 STYLE_DNA
- [ ] 身份像已确认的 `reference-character.png`（锚点可辨；角色线条符合当前风格，只有用户明确画法例外才额外保持）

## 错误与运行期补校准

| 情况 | 行为 |
|------|------|
| 设定图不合格 | 停 0.1，不落盘 |
| 胸像未过 0.2b 设定确认就落盘 | **禁止** |
| 首轮已生图 / 海报式成稿 | **路由错误**；停，回到 0.2 |
| 校准未过 QA 5 项 | 重生成，不得展示/入库 |
| 0.2b 设定非全身 | 重生成，不得展示/落盘 |
| 生图后无收尾问 | **未闭合**；同轮补问，不得进下一步 |
| 交付无确认问题 | **未闭合**；不得进下一步 |
| Step 0 中写了 shot-config / 进了 Step 1–5 | **路由错误**；停配图，从当前未闭合步重开 |
| `examples/{$STYLE}/` 空且用户要用该风格 | lazy 补 0.4（已启用 · 见上节多风格细则） |
| id 已存在 | 换 id 或确认覆盖 |
| 校准失败 / 用户暂不确认 | 重跑 0.4 或停止在样板态；不得交付正式配图 |
| 用户明确画法例外未生效 | 校准失败；补 `{IP_STYLE_EXCEPTION}` 到 prompt 后重跑，不得入库 |
| 当前 `$STYLE` 校准缺失 | 先跑 Step 1.5；lazy 补 0.4，**不得** single 或正式交付 |
| 连续 2 次锚点 QA 失败 | 问是否补校准 |
| 把正式配图当校准 | **禁止** |

## 分层提醒

- gimi `examples/` 多主题为 **Tier 2 实例**，非本模板默认
- 风格文件定义角色与场景的默认画法；IP 锁色进 `{IP_STYLE_ADAPT}`；只有用户明确指定时才追加「用户指定画法例外」
- **批内人稳（全 `$STYLE` · 合约级）**：同批多图时，头身比与脸龄须与当次所选**该风格校准图**同档；漂移 → 换更近姿势/主题校准重试，不得只靠加 prompt。各风格在 `examples/{$STYLE}/` 维护选图表（见实例 `ip.md`）；**新风格录入不必再发明本条**，只补校准图。富风格更易暴露，规则仍通用。细则 QA 见 `qa-checklist.md`。
- 禁止把本文件写成第二份 composition / 色纪律
- 禁止另造「用户向流程」与协议门禁不一致的第二套步骤
- **路由冲突时：** `SKILL.md` 文首「路由分流」优先（先拦 ImageGen 抢跑）
