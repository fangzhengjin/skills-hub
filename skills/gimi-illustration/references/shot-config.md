## 填写规则

> 决策流程以 `composition-patterns.md`「创意生成法八步」为准；本节只说明落盘到哪些字段。

| 八步 | 落盘字段 |
|------|----------|
| 1–2 核心信息 / 信息类型 | 核心信息 · 结构轴 · 构图 |
| 3 物件表意 | 物件表意 |
| 4 主载体 + 分工 | 隐喻：主载体 · 辅助物件 · 信息分工 |
| 5 视觉承诺（必） | **视觉承诺** · 地标特征 · 外参附图 · 域物件 · 硬物件结构 → **`visual-promise.md`** |
| 6 密度 + 阅读动线（T3′） | **density** · **阅读顺序** → 细则 **`composition-patterns.md`「阅读动线语法」** |
| 7 故事动线 | 隐喻：结构关系 · 故事动线（与阅读顺序对齐；序列见「序列构图语法」） |
| 8 标注对齐 | 标注词 → 细则 **`visual-promise.md` §E** |

**补充（仅 shot-config 独有）**

- **物件表意**：禁泛化替代原文具名物件；`$IP=none` 且分工需演员 → 读 `ip/none.md`
- **视觉承诺全家桶** → 只读 **`visual-promise.md`**；禁止在此复制长文
- **density / 阅读顺序** → 只读 **`composition-patterns.md`「阅读动线语法」**；`scenic` 必填阅读顺序；禁「砍标注数」当根治
- **色纪律（两层）**：批次表 = 整批摘要（摘自 `styles/{$STYLE}.md`）；隐喻「色与改动」= 当张 1 句取舍 + 改动优先线稿符号
- **标注词（硬默认）**：填 **2–5** 个短词，挂动线节点；意象/降级用泛称禁真名（§E）。**禁止**自行写「无 / 文档外 caption 承担说明」。仅用户明示「图内不要字 / 后期叠字」→ `无（用户要求）`。序列主路径节点名计入标注词
